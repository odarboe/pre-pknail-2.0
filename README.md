# PKNail 2.0

Pointknown internal geometry engine for converting point cloud-derived features into structured BIM/Revit elements.

## Current Phase

MVP development with Cognixlab.

## Purpose

PKNail 2.0 is intended to support a structured workflow for converting point cloud-derived geometry into design-ready BIM/Revit elements, with an emphasis on Architectural Intent modeling rather than literal point cloud overfitting.

## Core Components

- Revit add-in / placement engine
- Point cloud preprocessing tools
- Structured geometry JSON workflow
- Sample test rooms and validation cases
- Documentation and MVP acceptance criteria
